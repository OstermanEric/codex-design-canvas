# Changelog

## 0.1.0 — 2026-11-05

Initial local test plugin with project/one-off boards, stable labels, immutable revisions, annotations, canvas UI, stdio tools, a loopback browser viewer and self-contained runtime bundles. Source and loaded projects remain separate.

## Public GitHub Packaging — 2026-11-06

Prepared portable installation instructions, a generic Daylight concept demo, repository metadata and bundled dependency notices for the initial public source release.
