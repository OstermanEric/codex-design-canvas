# Feature Map

Implemented: project and one-off boards; stable numbered/lettered labels including aa after z; revision history; pinned/resolvable comments tied to revisions; shared selection; draggable cards; zoom; comparison filter; HTML/image import; project file inventory/README; stdio MCP; local browser viewer; host UI metadata; local install script.

Not implemented: hosted collaboration, Figma import, vector editing, automatic SwiftUI conversion, arbitrary JavaScript previews, automatic generation without a Codex turn.

Verification: storage/integration suite; installed-copy stdio launch with a minimal desktop PATH; Codex host plugin discovery; manual browser comparison, revision selection, annotations, one-off workspace creation, file import, variation allocation and clipboard context. Embedded-panel rendering remains unverified; advertising MCP Apps metadata is not proof of that UI rendering.
